# Projet_Calculatrice
# 🧮 Calculatrice Python avec CustomTkinter

Une calculatrice moderne développée en Python avec la librairie CustomTkinter.  
Elle permet d’effectuer des opérations mathématiques simples avec une interface graphique propre et intuitive.

## ✨ Fonctionnalités

- Addition ➕
- Soustraction ➖
- Multiplication ✖️
- Division ➗
- Exponentiation ^
- Gestion des nombres décimaux
- Suppression du dernier caractère (`del`)
- Réinitialisation complète (`CE`)
- Interface graphique moderne avec mode sombre

---

## 📸 Aperçu

Interface réalisée avec CustomTkinter :

- Design sombre
- Boutons interactifs
- Affichage dynamique des calculs

---

## 🛠️ Technologies utilisées

- Python 3
- CustomTkinter
